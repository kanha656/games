🎮 Python Mini Games

Welcome to my Python Mini Games repository! This project contains two simple games created using Python to practice programming, loops, conditional statements, user input, and the random module.

🕹️ Games Included
1. Stone Paper Scissors

A classic game where you play against the computer.

Controls:

s = Stone
p = Paper
c = Scissors

Rules:

Stone beats Scissors.
Paper beats Stone.
Scissors beats Paper.
If both choose the same option, it's a draw.

The computer randomly selects its choice, making every round different.

File: GAME.py

2. Number Guessing Game

A fun game where the computer randomly selects a number between 1 and 100, and you try to guess it.

How to play:

Run the game.
Enter a number between 1 and 100.
Follow the hints
